## 使用风险提示

服务商的官网、套餐、付款方式、试用和退款规则可能随时变化。本文提供购买前检查清单与备用机场选择建议，具体服务仍需在自己的设备和网络中验证。请核对 [机场风险监测](/risk-monitor/) 中的公开记录，并以服务商当前条款为准。

下单前值得确认的是：实际支付金额和周期、套餐限制、订阅导入方式、自动续费与退款条件，以及出现故障时的支持渠道。页面宣传语不能代替这些条款。

## 购买前先问自己

| 问题 | 为什么重要 |
|---|---|
| 主要用什么设备 | 决定选专属客户端、Clash、Shadowrocket 还是 v2rayN |
| 主要用途是什么 | 先确认服务条款、当地法规及设备兼容性；不要把地区或节点描述当作可访问保证 |
| 每月大概用多少流量 | 决定 50GB、100GB、200GB 还是不限时按量套餐 |
| 是否需要手机和电脑同时用 | 决定设备数、连接数和订阅兼容性 |
| 对客户端的熟悉程度 | 核对服务商支持的客户端与自己的系统，必要时先读对应客户端说明 |
| 是否有备用方案 | 评估服务中断对自己的影响，避免把关键工作依赖于单一第三方服务 |

如果你还不理解机场、节点和订阅链接，先看 [机场是什么](/posts/airport-node-subscription-guide/)。

## 套餐怎么选

### 第一次购买

首次购买前，先确认：

1. 试用是否存在、适用对象与限制是什么；试用条款不代表付费后的服务表现。
2. 计费周期、自动续费、取消方式及退款条件是否有明确说明。
3. 服务商支持的设备、客户端和导入流程是否与自己的设备匹配。
4. 需要时通过官方支持渠道询问故障处理与数据/账号政策。
5. 不因折扣或限时话术仓促购买长期套餐；按自身可承受的风险决策。

### 按使用情况核对套餐

| 使用情况 | 套餐选择参考 | 重点看 |
|---|---|---|
| 轻度网页、查资料 | 预计用量、计费周期和总价 | 有效期、流量扣减方式与退款条款 |
| 在线服务与办公 | 服务条款、设备兼容、隐私与安全要求 | 服务中断对自己的影响及支持渠道 |
| 视频与大流量用途 | 流量计算方式、有效期、限速规则 | 不将解锁宣传视为保证，并核对退款条款 |
| 手机电脑多端 | 客户端兼容、连接数与设备限制 | 订阅格式、支持系统及账户规则 |
| 备用机场 | 低成本月付或有效期明确的按量套餐 | 与主力服务商分开，核对有效期、流量规则和续费成本 |

## 付款前检查清单

付款前至少检查这些信息：

- 官网是否和站内测评链接一致，避免仿冒站。
- 是否有备用域名、公告页或客服入口。
- 套餐是否写清楚流量、周期、倍率、设备数。
- 是否支持 Clash、Shadowrocket、v2rayN 或专属客户端。
- 试用、退款、工单或售后条款是否明确，并保存下单时页面记录。
- 是否强推超低价年付、终身套餐。
- 最近是否出现在 [机场风险监测](/risk-monitor/) 的异常记录里。

如果页面只强调“极速、永不跑路、永久可用”，但没有套餐细节、售后方式和测试入口，要更加谨慎。

## 买完后怎么测试

如果已购买且需要排查客户端配置，可以按此流程检查；不要将结果外推为持续可用承诺：

1. 复制订阅链接，导入客户端。
2. 更新订阅，看节点是否完整出现。
3. 依据客户端和服务商文档检查订阅是否更新、配置是否报错。
4. 记录错误信息、发生时间、设备和网络环境，便于提交客服工单。
5. 如果某个第三方服务不可用，先查看该服务状态页、账号状态和官方帮助；不要据此推断服务商作出可用性保证。

Clash 用户可以配合 [Clash订阅导入失败排查](/posts/clash-subscription-troubleshooting/)；Windows 用户也可以看 [v2rayN 使用教程](/posts/v2rayn-guide-2026/)。

## 常见避坑点

### 不要只看最低价格

低价本身不能证明服务质量或风险水平。比较总价、流量规则、服务期限、退款与支持条款，并结合公开风险记录判断。

### 不要只看节点数量

节点数量不等于质量或特定服务可用性。确认套餐包含的功能、设备支持和售后范围，不要把宣传中的地区清单理解为第三方平台的兼容承诺。

### 不要把试用当长期表现

试用可能限制节点或流量，也可能处在非高峰时间。购买前要尽量在自己常用时段测试。

### 不要泄露订阅链接

订阅链接绑定账号和流量。公开分享可能导致流量被消耗、账号异常或订阅被重置。

### 不要只准备一个机场

如果你依赖 ChatGPT、远程办公、跨境电商或开发工具，建议购买并保留一个备用机场，或准备已验证可用的备用客户端与连接方式。主力与备用尽量选择不同服务商，并定期检查备用套餐有效期、剩余流量和连接状态；多买一份服务本身不能保证持续可用。

## 总结

下单前应读清套餐、计费、取消/退款和隐私条款，核对客户端兼容及公开风险信息，并保留购买凭证。试用、宣传中的速度或第三方平台访问表现，都不能保证后续付费服务持续可用。
