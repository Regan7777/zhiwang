## 🧠 什么是Clash节点？

**Clash节点**通常指客户端配置中的一个代理服务端入口。客户端按节点地址、协议和凭据建立连接，再由服务端转发目标请求；节点不一定在境外，是否能访问某个服务也需要具体核对。

### 节点工作原理

1. **本地设备 → Clash客户端**
   Clash在本地充当代理，接收请求。

2. **Clash客户端 → 节点服务器**
   客户端按配置连接服务端，由其转发到目标网站。

3. **节点服务器 → 本地设备**
   响应经相应连接返回；请求能否成功取决于配置、网络与目标服务。

> 代理增加了转发环节，并不自动降低延迟或获得平台访问资格。

## 📊 Clash节点协议分类

| 协议 | 说明 | 使用时核对 |
|------|------|------|
| **VMess** | 一种代理协议 | 客户端内核是否支持配置中的传输方式 |
| **Shadowsocks / ShadowsocksR** | 不同的代理类型 | 订阅中的类型与加密方式是否受支持 |
| **Trojan** | 使用 TLS 的代理协议 | 服务器、端口和 TLS 配置是否完整 |
| **Snell / SOCKS5** | 不同的代理类型 | 按服务商说明导入，不能互换类型名称 |

客户端支持的协议取决于所带内核与版本。新手优先使用服务商提供的兼容订阅，不必先手动改协议；协议名称本身不能证明速度或稳定性。[Mihomo 出站代理文档](https://wiki.metacubex.one/config/proxies/)

## 🚀 新手如何使用Clash节点

### 1️⃣ 下载Clash客户端

- **Windows / macOS / Linux**：[Clash Verge Rev 教程](/posts/clash-verge-guide-2026/) / [FlClash 教程](/posts/flclash-guide-2026/)
- **Android**：FlClash / [Clash Meta 教程](/posts/clash-for-android-guide-2026/)
- **iOS**：先查看 [iPhone 客户端安装说明](/posts/shadowrocket-guide-2026/)，再核对所选应用的订阅格式；不要直接套用桌面版 Clash 的菜单与配置步骤。

### 2️⃣ 获取节点订阅

- 提供兼容订阅的机场（例如：[神行加速](/posts/shenxingjiasu-review-2026/) / [月之暗面](/posts/yuezhi-anmian-review-2026/) / [云界线](/posts/yunjiexian-review-2026/)）。购买前确认订阅领取条件和目标客户端格式。

### 3️⃣ 导入节点

1. 打开Clash客户端
2. 进入 **配置文件/Config**
3. 选择 **导入远程订阅** 或 **本地导入**
4. 粘贴订阅链接或选择配置文件
5. 点击 **应用/启用**

### 4️⃣ 选择代理策略

- **Global（全局模式）**：进入内核的流量使用全局策略组，需先在该组选择节点
- **Rule（规则模式）**：按当前配置的规则决定流量去向
- **Direct（直连模式）**：进入内核的流量直接连接

> 日常可从 **Rule 模式**开始，但实际分流取决于订阅中的规则。模式选择与系统代理、VPN 或 TUN 的开启是不同设置。[Mihomo 运行模式说明](https://wiki.metacubex.one/config/general/#运行模式)

### 5️⃣ 检查延迟与实际连接

- 查看客户端的测试说明；常见延迟测试结果不是下载带宽。
- 固定目标与测试条件，记录连接是否成功、响应与失败信息。
- 在自己的常用时段对照备用节点；单次数字不能证明持续稳定。

### 6️⃣ 使用流媒体（Netflix / YouTube / Disney+）

- 选择已确认支持当前客户端订阅格式的节点，并验证目标平台能否播放
- 若配置包含相关策略组，按配置说明选择；不是所有订阅都有“流媒体策略”
- 实际能否播放取决于节点、账号与平台规则

## ❌ 常见问题与避坑指南

1. **节点无法连接**
   - 检查订阅链接是否过期
   - 网络环境是否限制代理

2. **延迟高 / 掉速严重**
   - 切换节点
   - 晚高峰可选择备用节点

3. **客户端报错 / 闪退**
   - 更新到最新版
   - 清理旧配置后重新导入

4. **核对购买与维护条件**
   - 价格不能证明节点数量、维护质量或实际表现
   - 查看套餐条款、客户端更新、售后与风险记录

## 🧭 新手节点选择建议

| 场景 | 先核对 | 说明 |
|------|----------|------|
| 日常连接 | 客户端与订阅格式 | 不按协议名推断速度或稳定性 |
| 流媒体使用 | 平台官方说明、账号和目标功能 | “专用节点”标签不保证播放或会员资格 |
| 预算有限 | 付款周期、流量和设备数 | 先比较短周期成本与退款条件 |
| 长期使用 | 先筛选通用订阅，再验证常用节点 | 专属客户端不能直接套用本教程；客服领取的订阅需先确认格式 |
