## 使用风险提示

应用无法访问可能源于服务状态、账户资格、应用版本、系统代理、DNS 或本地网络。请先阅读平台通知和所在地区规则；本文只指导诊断自己设备的连接配置，不承诺更换节点、代理或地区能绕过平台限制。

很多用户会遇到这种情况：Google 能打开但 YouTube 卡，YouTube 能看但 GitHub 拉不动，Gmail 登录异常，或者只有某个软件不走代理。单应用打不开时，不要直接判断“机场坏了”，要先定位是哪一层出问题。

## 快速判断表

| 现象 | 可能涉及的层面 | 先核对 |
|---|---|---|
| 多个网站都无法连接 | 本地网络、系统代理、DNS 或客户端 | 其他网络是否正常；代理是否误开；客户端状态和系统时间 |
| 只有一个网站/应用异常 | 服务状态、应用版本、账户或单应用代理设置 | 官方服务状态、应用更新、完整错误提示及账户通知 |
| 网页可用但 Git/IDE 不可用 | 终端代理设置、Git 协议、公司网络策略 | 工具是否使用代理；HTTPS/SSH 配置；组织网络政策 |
| 能登录但部分功能不可用 | 账户资格、订阅、地区或平台政策 | 官方账户页面与帮助中心；遵守服务地区要求 |
| 开启代理后其它连接异常 | 代理模式、分流规则、DNS 或多个代理冲突 | 系统代理与客户端规则；是否同时运行多个代理 |

## 第一步：先测基础连接

按顺序测试：

1. 记下时间、设备、应用版本、网络类型和完整错误提示。
2. 查看目标平台官方状态页/帮助中心和账户通知。
3. 检查系统代理、所用客户端与单应用代理设置；避免同时运行互相冲突的代理客户端。
4. 若你有权使用该网络配置，可在遵守平台规则及当地法律的前提下，每次只改变一个本地配置项并记录结果。
5. 若官方提示账户、订阅或地区资格问题，按官方流程处理；不要反复变更地区或借用账号。

分流规则决定进入代理内核的流量去向；系统代理则供遵循该设置的应用把请求交给客户端，两者不属于同一组选项。检查时应分别记录，避免误以为切换规则模式就会让所有应用使用代理。

## Google 打不开

优先检查：

- 系统代理是否开启。
- 浏览器是否使用了独立代理插件。
- Clash 或 v2rayN 是否选中了可用节点。
- DNS 是否被污染或解析失败。
- 是否同时运行多个代理软件。

如果其他服务正常而浏览器仍无法连接，可检查本机 DNS、代理和浏览器配置。若多款客户端均异常，再查看 [Clash订阅导入失败排查](/posts/clash-subscription-troubleshooting/)中的本地诊断步骤；不要仅凭一次失败断定节点或服务商故障。

## YouTube 打不开或很卡

播放缓冲可能与设备、应用、网络质量、内容或账号状态有关。可记录：

- 应用版本、设备、网络类型和发生时间。
- 同一视频的播放质量、缓冲频率及应用显示的错误码。
- 服务状态、账户资格与应用内通知。
- 若涉及第三方代理服务，核对其实际计费、隐私和服务条款，不据宣传标签推断平台兼容。

可参考[流媒体平台限制与官方排查入口](/rankings/streaming/)；不能以普通网页连通推断付费内容、家庭规则或其它功能可用。

## GitHub 打不开或 Git 拉不动

开发者常见问题是浏览器能打开 GitHub，但终端、IDE、Git、npm、Docker 不走代理。

排查重点：

- 浏览器和终端是否使用同一个代理。
- Git HTTPS 是否配置了代理。
- SSH 连接是否需要单独配置。
- 代理或 TUN 设置是否为自己所需、且符合设备和组织网络政策。
- 公司网络、防火墙或 DNS 是否拦截。

网页浏览先核对浏览器是否遵循系统代理，或是否有独立设置；开发工具链也可能需要在相应工具中单独配置。

## Gmail 登录异常

如果 Gmail 无法登录，先查看 Google 账户安全提示和登录活动：

- 按官方流程完成账户验证并检查是否有未知登录。
- 不要把验证提示简单归因于 IP，也不要通过切换地区尝试规避验证。
- 检查浏览器扩展和应用版本，避免在共享设备保存凭据。
- 多项 Google 服务同时异常时，核对官方状态/帮助信息及本地网络。

## 常见问题

### 为什么 Google 能开但 GitHub 不能

可能涉及 DNS、终端代理、SSH/HTTPS 配置、组织网络限制或 GitHub 服务状态。检查实际使用的客户端和协议，并查看官方状态；不要在不了解组织政策时改动公司设备代理。

### 为什么浏览器能用，App 不能用

先核对应用是否遵循系统代理、操作系统设置和客户端日志。只有在理解其影响并符合设备/组织政策时，才调整代理模式；故障也可能来自平台或账户。

### 为什么换节点后 Gmail 要验证

按 Google 账户安全通知完成验证，并检查是否有未知登录。不要把更换网络地区当作账号验证解决建议，也不要向第三方提供验证码。

### 一个机场能解决所有应用吗

不一定。各服务有自己的账户资格、可用地区和应用要求；网络连接成功并不等于平台功能可用。请查看对应官方规则，不因本文购买代理服务。

## 总结

单个应用打不开时，先区分本地网络/代理配置故障与平台服务、账户、订阅或地区资格问题。记录错误信息，检查应用与系统配置，再按官方说明处理；不要通过切换国家、购买账号或代理服务绕过平台规则。
