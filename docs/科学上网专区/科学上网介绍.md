“科学上网”“梯子”和“机场”是中文网络中的常见称呼，分别可能指一种用途、一个软件或一项服务。它们不属于同一分类。先分清工具与服务商，才能判断需要下载什么、向谁付费，以及发生故障时该检查哪一层。

<!-- more -->

## 这些名称分别是什么意思？

| 名称 | 指什么 | 与其他项目的关系 |
|---|---|---|
| 科学上网／翻墙 | 日常语境中对通过其他网络路径访问互联网资源的称呼 | 不是某一种协议或产品 |
| VPN | 虚拟专用网络技术；日常也指提供 VPN 连接的商业服务 | 可用于企业或家庭网络接入，也有消费服务 |
| 代理协议 | 规定客户端与代理服务器如何通信 | 需要相应的客户端与服务器支持 |
| 客户端 | 在设备上导入配置、连接节点的软件 | 安装客户端不等于已经取得节点服务 |
| 机场 | 提供代理节点、套餐和订阅的服务商俗称 | 属于商业服务称呼，不是一种协议 |
| 软路由 | 用通用硬件与软件承担路由功能的设备方案 | 可以运行多种网络服务，不是使用代理的必需品 |

VPN 技术和机场服务可以存在交集。不能把“VPN”和“机场”直接当成互斥的协议，也不能仅凭服务商自称哪一类就判断安全、速度或稳定性。

## 一次连接涉及哪些环节？

典型代理连接可以简化为：

**设备上的应用 → 客户端或代理内核 → 服务端节点 → 目标网站**

具体哪些应用流量进入客户端，取决于系统代理、应用自身设置、VPN 接口、TUN 和分流规则。即使节点能连接，目标服务还可能有账户、订阅、设备与地区要求。

在 Mihomo 中，规则、全局和直连是内核处理已进入流量的方式；开启哪种模式，与是否打开系统代理或 TUN 是两项设置。[Mihomo 全局配置说明](https://wiki.metacubex.one/config/general/)

## 协议、内核与客户端如何区分？

- **Shadowsocks、VMess、Trojan 等**是不同的代理协议或协议类型，需要核对具体配置。
- **V2Ray、Xray、Mihomo**是相关软件项目或内核，不能把项目名直接当作速度等级。
- **Clash Verge Rev、FlClash、v2rayN 等**是客户端，支持哪些协议取决于其版本及所使用的内核。
- **WireGuard**是 VPN 隧道方案；项目工作方式可查阅[官方介绍](https://www.wireguard.com/)。

本页没有协议对比实测，不提供“SS 最快”“V2Ray 最稳”或“Trojan 适合永久使用”等排序。服务器负载、路径、配置与本地网络都可能影响结果。

## 下载客户端后还需要什么？

客户端通常需要服务商或自己管理的服务器配置。机场订阅是获得配置的一种方式，也可以使用组织提供的连接或自行维护服务器，因此机场并不是所有网络用途的必需品。

一般流程是：选择适合设备的客户端，取得匹配格式的配置，导入并启用，然后检查实际连接。服务商可能直接提供专属客户端，也可能要求向客服领取订阅；应先确认领取条件。

- 需要了解订阅和套餐，先看[机场入门](/posts/airport-node-subscription-guide/)。
- 需要选择软件下载入口，查看[工具与客户端下载指南](/posts/airport-tools/)。
- 已经取得订阅但导入失败，查看[订阅故障排查](/posts/clash-subscription-troubleshooting/)。

## 加密和隐私能解决什么？

VPN 隧道、代理链路和网站的 HTTPS 属于不同环节。连接网络服务不会自动解决钓鱼、恶意安装包、账号被盗或网站自身追踪的问题；服务商的日志与隐私政策仍然重要。

EFF 提醒，VPN 不能使用户完全匿名，也不能保证通过视频网站的地区限制。选择前应评估运营者与数据处理方式，而不只看“安全”宣传。[EFF：选择适合自己的 VPN](https://ssd.eff.org/module/choosing-vpn-thats-right-you)

## 机场、自建和软路由怎么取舍？

机场把节点与套餐作为服务交付，用户仍需承担费用及服务中断风险；自建方案需要自己负责服务器、配置、维护和费用。两者的总成本与连接表现取决于具体条件，不能预设自建一定更便宜或机场一定更稳定。

软路由适合需要统一管理多设备网络的用户，也会增加路由、DNS 和维护复杂度。没有这些需求时，可以先在单台设备上理解客户端与订阅，再考虑是否需要[软路由](/posts/soft-router-guide-2026/)。

如果日常工作依赖连接，建议准备与主力不同服务商的备用机场。可按低频用量选择短周期或有效期明确的按量包，并定期验证剩余流量、到期时间与设备连接。

## 新手选择顺序

1. 确认自己的设备系统、应用用途及目标服务规则。
2. 从项目或厂商的可核对入口选择客户端。
3. 核对服务商套餐周期、流量、订阅格式、设备数和退款条件。
4. 在自己的设备和网络中验证，再决定是否长期使用。
5. 保存购买记录，保护订阅链接，并检查备用方案。

本文没有“几分钟必定可用”或适用于所有用户的单一组合。可结合[VPN 与机场的优缺点比较](/posts/is-vpn-or-airport-better-pros-cons-analysis/)进一步判断。
