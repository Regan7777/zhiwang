## 站点定位

织网 是一个机场推荐与信息整理站，主要维护机场推荐、套餐与客户端资料、科学上网教程、风险监测和结构化数据。

自 2026年8月18日起，织网 不再自行开展测速、晚高峰实测、流媒体测试或 AI 可用性测试。本站不发布服务性能结论；用户应在自己的账号、设备与网络环境中完成验证。

本站的目标不是给出“永久最好”的机械答案，而是把价格、流量、试用、客户端、场景匹配、售后和购买风险放在同一个页面里，方便读者先筛选，再自行短期验证。

## 作者与责任范围

本站由织网维护，负责：

- 整理服务商官网公开的价格、流量、试用、客户端、订阅和规则。
- 收集并整理用户投稿的实际使用反馈与客观体验记录。
- 按新手、低价、Clash、ChatGPT、流媒体等场景给出推荐。
- 记录官网异常、客服失联、套餐变化、退款与支付风险。
- 维护教程、商业披露、页面更新日期和纠错入口。

本站不再是当前测速或测试数据的生产方。如果页面结论与服务商官网后台或读者自己的实际环境不一致，应按信息类型分别以最新来源为准。

## 编辑原则

| 原则 | 具体做法 |
|---|---|
| 推荐与测试分开 | 织网 负责整理推荐，不再自行测速，用户投稿单列 |
| 不发布性能测试结论 | 套餐、客户端与风险资料均应以各自来源和核对日期阅读 |
| 风险前置 | 优先提示官网、客服、退款、支付、续费和服务中断风险 |
| 不作永久承诺 | 不承诺长期可用、固定速度、绝对安全或永久解锁 |
| 商业关系透明 | 推广入口标记 sponsored / nofollow，不以佣金自动改变排序 |
| 用户最终验证 | 建议先试用、月付或短周期购买，再在自己的环境中判断 |

完整规则见 [机场推荐方法与资料来源](/methodology/)。

## 商业披露

部分服务商官网入口可能包含邀请码、推广参数或联盟追踪参数。这类链接不会改变风险提示和推荐原则，构建时会自动补充 `rel="sponsored nofollow noopener noreferrer"`。

本站不建议读者因为优惠码、返利、最低价或单张历史测速截图直接购买长期套餐。涉及付款、USDT、交易所、账号注册和跨境网络访问时，请自行确认当地规则、服务条款、资金风险和账号安全要求。

## 更新规则

本站今后优先更新：

- 推荐顺序、适合场景和不适合人群。
- 套餐价格、流量、试用、客户端和订阅规则。
- 官网入口、客服、退款、支付和停止推荐等风险状态。
- 教程、商业披露和历史资料标签。

本站不再新增自产的测速、实测或测试截图。旧性能截图、数值与结论已从公开评测及榜单移除，页面保留的套餐来源与编辑记录不作为当前性能证明。
